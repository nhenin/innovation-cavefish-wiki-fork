# Cavefish Wiki Snapshot

Cavefish is an intent-oriented light-client R&D workstream for private transaction submission on UTxO-based blockchains.

This repository is a public wiki snapshot for the workstream. It is meant as an entry point into the design notes, progress reports, execution strategies, and closing material around Cavefish.

## Why It Matters

Cavefish explores a missing capability on Cardano and similar UTxO chains: submitting transactions through an intent/light-client layer while preserving privacy properties and keeping the transaction strategy grounded in implementable Haskell code.

The work sits at the boundary between protocol design, applied cryptography, zero-knowledge circuits, product framing, and execution architecture.
